# Sonitpur Polytechnic Class Test 1 Results

This is a static GitHub Pages website. `index.html` is the complete page; it has no Python, server, package installation, or build step. Place it at the repository root and select the `main` branch and `/ (root)` as the GitHub Pages publishing source.

## Privacy warning

Do not publish this file in a public repository or public website. It contains all 47 students' names, roll numbers, marks, calculation details, and monitoring logs. The roll-number-and-name form only filters what the page displays. Anyone who can access the HTML can inspect every student's record.

A private GitHub repository does not automatically make a GitHub Pages site private. Check GitHub's [Pages site visibility documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site) before publishing. For student-specific privacy, the site needs authenticated access backed by a service that does not send the full class report to every visitor.
